## donjon.bin.sh -- D&D 5e Tools
A massive collection of random generators and lookup tools. Below are the 5e-specific resources.

**URL:** https://donjon.bin.sh/

### Lookup & Reference
- **Quick Reference** -- Actions, conditions, environmental effects (crobi's reference) -- https://donjon.bin.sh/5e/quickref
- **Spell Sheet** -- List spells by class, level, school, etc. -- https://donjon.bin.sh/5e/spells/
- **Monster List** -- List monsters by size, type, tags, alignment, etc. -- https://donjon.bin.sh/5e/monsters/
- **Magic Items** -- List magic items by type, rarity, etc. -- https://donjon.bin.sh/5e/magic_items/

### Encounter & Combat
- **Encounter Size Calculator** -- Calculate encounter size based on party size and level -- https://donjon.bin.sh/5e/calc/enc_size.html
- **Initiative Tracker** -- Track initiative and turn status -- https://donjon.bin.sh/5e/initiative/
- **Random Encounter Generator** -- Select monsters based on encounter level and environment -- https://donjon.bin.sh/5e/encounter/

### Loot & Treasure
- **Random Treasure Generator** -- Coins, gems, art objects, and magic items -- https://donjon.bin.sh/5e/treasure/
- **Random Magic Shop Generator** -- Generate random magic shops with items from the DMG -- https://donjon.bin.sh/5e/magic/shop.html

### Dungeon & Adventure
- **Random Dungeon Generator** -- Generate a dungeon with random features, monsters, and traps -- https://donjon.bin.sh/5e/dungeon/
- **Five Room Dungeon Generator** -- Generate a dungeon using Johnn Four's 5 Room Dungeon structure -- https://donjon.bin.sh/5e/5_room/
- **Random Generator** -- Generate random NPCs, loot, magic items, traps, etc. -- https://donjon.bin.sh/5e/random/
- **RWBY Team Generator** -- RWBY inspired teams of adventurers/NPCs -- https://donjon.bin.sh/5e/rwby/

### General (non-5e but useful)
- **Fractal World Generator** -- Generate a random world map -- https://donjon.bin.sh/world/
- **Fantasy Name Generator** -- Generate random names for characters, events, taverns, etc. -- https://donjon.bin.sh/fantasy/name/
- **Fantasy Calendar Generator** -- Generate a calendar of months, weeks, lunar cycles, etc. -- https://donjon.bin.sh/fantasy/calendar/
- **Medieval Demographics Calculator** -- Based on Medieval Demographics Made Easy by S. John Ross -- https://donjon.bin.sh/fantasy/demographics/
- **Random Town Generator** -- Generate a random town or city map -- https://donjon.bin.sh/fantasy/town/
- **Random Inn Generator** -- Generate random inns and taverns, including menu, patrons, and rumors -- https://donjon.bin.sh/fantasy/inn/
- **Random Adventure Generator** -- Generate random adventure elements based on the Dungeon Master's Design Kit -- https://donjon.bin.sh/fantasy/adventure/
- **Random Weather Generator** -- Generate random weather, from clear to storms -- https://donjon.bin.sh/weather/
- **Treasure Map Generator** -- Generate a random treasure map with marker icons, names, and clues -- https://donjon.bin.sh/fantasy/treasure_map/

## Sly Flourish -- Lazy GM Resource Document
A comprehensive collection of random tables, adventure frameworks, and DM tools from Sly Flourish / Mike Shea.

**URL:** https://slyflourish.com/lazy_gm_resource_document.html

### What's Inside
- **Random chambers** -- 15 dungeon types with random room features
- **Random underground connectors** -- Corridors, stairs, shafts, tunnels
- **Random items** -- Weapons, item conditions, origins, spell effects, mundane items
- **NPC creation** -- Quick NPC traits, motivations, secrets
- **Random encounters** -- Wilderness travel framework (weather, encounters, landmarks)
- **Fantastic locations** -- Modular location elements for building adventures
- **Secrets and clues** -- Tables for generating clues the party can discover
- **Adventure framework** -- Step-by-step wilderness journey procedures
- **Spell effects table** -- Random magical effects for items and relics

**Best for:** Session prep on the fly -- generating quick dungeon rooms, NPC traits, loot ideas, and wilderness encounters without prep time.

**Best for:** Breaking through creative blocks during session prep. Tap for unexpected twists, NPC motivations, or scene ideas when you need something fresh.
